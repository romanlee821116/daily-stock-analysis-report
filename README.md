# 台股每日追蹤

每個交易日自動更新的台股報告，線上閱讀：**https://romanlee821116.github.io/daily-stock-analysis-report/**

## 每日盤前分析

開盤前的重點整理：今日結論、關鍵數據看板（台指期夜盤、美股、費半、殖利率、原油等）、籌碼與過熱指標、隔夜重要消息與產業影響、產業轉強／轉弱一覽。

## ETF 每日追蹤

追蹤台股主動式 ETF 的持股異動：產業資金流向、個股淨買超／淨賣超排行、多檔 ETF 同方向操作的共識訊號、最大檔 ETF 專章，以及全體 ETF 淨買賣超一覽。

> 報告為公開資料的事實彙整與分類統計，不構成投資建議。
